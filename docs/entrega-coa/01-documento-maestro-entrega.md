# 2. Resumen Ejecutivo

Agro360 es una aplicación web multirol para capturar, almacenar y gestionar caracterizaciones prediales agropecuarias en Santander, Colombia. Cubre todo el flujo: el asesor visita el predio en campo, el analista hace la evaluación crediticia y el productor consulta los resultados.

El sistema está construido sobre Next.js 16, React 19, TypeScript y Supabase (PostgreSQL, Auth y Storage), y se despliega en Vercel con funciones serverless. Incluye un formulario de 9 pasos, generación de PDF, notificaciones por correo, captcha, firmas digitales y exportación a CSV.
